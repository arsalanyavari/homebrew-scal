# Homebrew Tap for Scal

This repository is purely a Homebrew tap for the [scal](https://github.com/arsalanyavari/scal) project. 

`scal` is a Rust implementation of the classic `jcal` utilities. When you install `scal` via this tap, it automatically includes the `sdate` and `sstat` tools as well.

## Installation

You can install it directly via Homebrew on macOS or Linux by running:

```bash
brew tap arsalanyavari/scal
brew install scal
```

Alternatively, you can install it using a single command:

```bash
brew install arsalanyavari/scal/scal
```

For more information, source code, and other installation methods, please visit the main [scal repository](https://github.com/arsalanyavari/scal).
